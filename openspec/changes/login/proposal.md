# Proposal

## Why

Друзья хотят пользоваться личной CRM, но сейчас приложение показывает всем один список контактов. Вход по ссылке из письма даёт каждому свой список и защищает записи других людей.

## What Changes

- **BREAKING** Доступ к контактам, группам и напоминаниям требует входа. Первый успешный вход создаёт аккаунт.
- На экране входа можно запросить одноразовую ссылку. В шапке после входа видны почта и кнопка «Выйти». Выход завершает вход только на текущем устройстве.
- Каждый видит и меняет только свои контакты, заметки, группы и напоминания. Чужая карточка по прямой ссылке открывает «Контакт не найден».
- Существующие контакты и группы переходят аккаунту владелицы. Записи, заметки и связи сохраняются. Демо-данные также принадлежат этому аккаунту.
- Письма локально и в автотестах получает Mailpit, на сервере их доставляет Unisender Go. Отправитель согласован: «Личная CRM» <`noreply@завяжи-узелок.рф`>.
- Отдельный браузерный тест проверяет изоляцию в обе стороны. Главный сценарий добавления контакта, поиска и заметки остаётся отдельным тестом и начинается со входа.

## Capabilities

### New Capabilities

- `login` — вход по письму, сессии по устройствам, разграничение доступа к данным и перенос прежних записей владелице.

### Modified Capabilities

- `groups` — личный список групп, уникальность названий в рамках аккаунта, выбор и фильтрация по своим группам.
- `keep-in-touch` — свои напоминания и изменения только для своих контактов. В другом браузере данные видны после входа под той же почтой.
- `delete-contact` — удалить контакт может только его владелец. Для чужого номера сервер отвечает так же, как для отсутствующей записи.

## Impact

Затронуты страницы CRM, серверные запросы и операции записи, схема PostgreSQL, демо-данные, Docker, проверки в GitHub и процедура выкатки. Для входа используется Better Auth Magic Link, для отправки — Nodemailer.

## Решения для проверки

- Для согласованного поведения при сбое отправки предложен текст «Не получилось отправить ссылку. Попробуй ещё раз». Последняя успешно отправленная ссылка продолжает действовать до истечения срока.

## Открытый вопрос

- Перед реализацией переноса уточнить у владелицы, откуда брать её почту для существующих записей и демо-данных.
