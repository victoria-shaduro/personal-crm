# Tasks

Для каждого сценария в дельтах OpenSpec добавить отдельный тестовый случай или обновить его существующий тест. Сначала запустить тест и увидеть ожидаемое падение, затем реализовать изменение и повторить проверку. Точные сроки проверять с управляемым временем. Для браузерных тестов использовать настоящие PostgreSQL и Mailpit.
