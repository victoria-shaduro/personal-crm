# Spec Delta

## MODIFIED Requirements

### Requirement: Создание и список групп

Приложение MUST открывать с главной экран «Группы», показывать группы пользователя в алфавитном порядке и принимать произвольное название длиной от 1 до 200 символов после удаления пробелов по краям. Повтор названия в любом регистре в пределах одного аккаунта MUST отклоняться.

#### Scenario: Создание групп
- **WHEN** пользователь создаёт «Теннис» и «  Семья  » на экране «Группы»
- **THEN** после обновления страницы в списке видны «Семья», затем «Теннис»

#### Scenario: Пустое название
- **WHEN** пользователь отправляет название из одних пробелов
- **THEN** форма показывает ошибку и список групп сохраняется

#### Scenario: Длинное название
- **WHEN** пользователь отправляет название длиннее 200 символов
- **THEN** форма показывает ошибку и сохраняет введённый текст для правки

#### Scenario: Повтор названия
- **WHEN** пользователь вводит «  семья  » при существующей группе «Семья»
- **THEN** форма сообщает о повторе, в списке остаётся одна «Семья»

#### Scenario: Одинаковое название у разных владельцев

- **WHEN** два пользователя создают в своих аккаунтах группу «Друзья»
- **THEN** в каждом аккаунте видна одна своя группа «Друзья».

### Requirement: Одна группа на контакт

Формы добавления и редактирования MUST давать выбрать одну собственную группу или вариант «Без группы». Карточка MUST показывать текущую группу или «Без группы». Смена группы MUST сохраняться вместе с остальными полями контакта.

#### Scenario: Назначение при добавлении
- **WHEN** пользователь добавляет контакт и выбирает «Семья»
- **THEN** карточка показывает «Семья» и контакт виден в этой группе на главной

#### Scenario: Добавление без группы
- **WHEN** пользователь добавляет контакт с вариантом «Без группы»
- **THEN** карточка показывает «Без группы», контакт виден в одноимённом фильтре

#### Scenario: Смена группы
- **WHEN** пользователь меняет в форме «Семья» на «Теннис» и сохраняет контакт
- **THEN** после обновления карточка показывает «Теннис», а среди фильтров групп контакт виден только в «Теннис»

#### Scenario: Снятие группы
- **WHEN** пользователь сохраняет контакт с вариантом «Без группы»
- **THEN** контакт исчезает из прежней группы и появляется в фильтре «Без группы»

#### Scenario: Сохранение с ошибкой
- **WHEN** пользователь выбирает другую группу, оставляет имя контакта пустым и сохраняет форму
- **THEN** форма показывает ошибку и сохраняет выбор, а в карточке остаётся прежняя группа

#### Scenario: Удаление контакта
- **WHEN** пользователь подтверждает удаление тестового контакта, который входит в группу
- **THEN** контакт исчезает из списка, а группа остаётся на экране «Группы» и в фильтре

#### Scenario: Номер чужой группы в запросе

- **WHEN** пользователь пытается передать серверу номер чужой группы при добавлении или редактировании своего контакта
- **THEN** приложение сообщает, что группа не найдена. Изменения не сохраняются.

### Requirement: Фильтрация общего списка

На главной MUST быть фильтр «Все контакты», «Без группы» и все группы пользователя. «Все контакты» MUST быть выбран по умолчанию. Фильтр и поиск по имени MUST применяться вместе и сохраняться в адресе. Блок «Пора связаться» MUST показывать все подходящие напоминания пользователя независимо от этих полей.

#### Scenario: По умолчанию видны все контакты
- **WHEN** пользователь открывает главную без параметров
- **THEN** показаны собственные контакты с группой и без группы

#### Scenario: Группа без контактов
- **WHEN** пользователь выбирает недавно созданную пустую группу
- **THEN** группа остаётся выбранной и список показывает, что в ней пока нет контактов

#### Scenario: Совместная работа фильтра и поиска
- **WHEN** пользователь вводит имя и выбирает группу, затем обновляет страницу
- **THEN** видны только совпадающие контакты в этой группе, оба поля и состав напоминаний сохраняются

#### Scenario: Очистка поиска
- **WHEN** пользователь очищает поисковый запрос при выбранной группе
- **THEN** видны все контакты выбранной группы

#### Scenario: Группа из адреса не существует
- **WHEN** пользователь открывает адрес с несуществующей группой и запросом по имени
- **THEN** фильтр показывает «Все контакты», а запрос применяется ко всему списку

#### Scenario: Чужая группа в адресе

- **WHEN** пользователь открывает главную с номером чужой группы и запросом по имени
- **THEN** фильтр показывает «Все контакты», запрос применяется только к своим контактам.

### Requirement: Данные после обновления

Обновление MUST сохранять существующие контакты, заметки и напоминания. Существующие группы и назначения контактов MUST сохраняться у владелицы.

#### Scenario: Контакт из предыдущей версии
- **WHEN** после обновления владелица входит под своей почтой и открывает прежнюю карточку контакта с заметкой и запланированной датой
- **THEN** заметка и дата сохранены, контакт доступен в прежней группе или в фильтре «Без группы», если группы не было
