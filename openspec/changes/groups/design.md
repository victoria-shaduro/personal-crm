# Design

## Context

Главная получает поиск по имени из адреса и загружает напоминания отдельно. Добавление и редактирование используют общую форму и серверные действия. PostgreSQL хранит контакты и заметки.

## Goals / Non-Goals

Один источник назначения группы для форм, карточки и фильтра. Проверки используют текущие серверные действия и локальную базу. Переименование и удаление групп, Playwright и CI остаются за пределами изменения.

## Decisions

- Одно назначение представлено необязательным внешним ключом `contacts.group_id` и индексом. Это позволяет сохранить данные контакта и назначение одним запросом. Запросы фильтра сравнивают `group_id` с выбранным идентификатором или проверяют `NULL`.
- `groups` хранит название для отображения и нормализованное название с ограничением уникальности. Сервер обрезает пробелы и приводит ключ к нижнему регистру. Ограничение базы также обрабатывает одновременные попытки создать одинаковые группы.
- Общее поле поиска и фильтра синхронизирует `q` и `group` в адресе. `group` содержит идентификатор, `ungrouped` или отсутствует. Сервер сверяет выбор со списком групп. Карточка получает название по ключу. Обычный HTML-список выбора работает с клавиатурой и на телефоне.
- Проверки на Vitest используют отдельную локальную базу PostgreSQL для интеграционных сценариев. Проверки форм и адресов запускаются без базы.

## Risks / Trade-offs

- При смене группы во время ввода поиск может потерять текст. Один компонент управляет обоими полями и учитывает ещё не отправленный текст при изменении группы.
- Ошибка сохранения может прервать работу с формой. Отправка сохраняет выбранные значения, а сервер сообщает об ошибке по-русски.

## Migration Plan

Миграция добавляет таблицу, необязательное поле, внешний ключ и индекс. Прежние записи остаются на месте, поле группы у них пустое. Текущая выкладка применяет миграцию перед запуском нового образа. Ручной откат меняет только образ. Предыдущая версия может работать с расширенной схемой, а группы и назначения доступны при следующем запуске новой версии.
