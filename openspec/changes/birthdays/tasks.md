### Ручная проверка

Проверять в браузере на локальной тестовой базе. Для календарных границ отсчитывать дни от сегодняшней даты в Новосибирске. Для строк с конкретным днём использовать изолированное локальное окружение с выставленной датой, например одноразовую виртуальную машину. В проверке часового пояса открыть браузер с часовым поясом Лос-Анджелеса в момент, когда по Новосибирску уже 01:00 нового дня. Для проверки обновления подготовить тестовый контакт в предыдущей версии перед запуском миграции.

| Сценарий | Действие и ожидаемый результат |
| --- | --- |
| Создание контакта без даты рождения | Добавить контакт с именем и пустой датой. Открыть карточку и убедиться, что строки «Дата рождения» нет. |
| Создание контакта с полной датой | Добавить контакт с датой 12 мая 1990 года. Увидеть дату в карточке и те же значения при редактировании. |
| Дата без года | Указать 29 февраля, оставив год пустым. Увидеть «29 февраля» в карточке и пустой год в форме. |
| Изменение и очистка даты рождения | Сменить сохранённую дату и открыть карточку. Затем очистить все части даты и сохранить. Сначала видна новая дата, после очистки строка исчезает. |
| Контакт из предыдущей версии | После миграции открыть заранее подготовленный контакт. Проверить группу, заметку и срок общения, затем убедиться, что дата рождения в форме пуста. |
| Неполный день рождения | При редактировании заполнить только день и сохранить. Проверить ошибку и сохранённый ввод, затем проверить прежнюю дату в карточке в другой вкладке. |
| Несуществующая дата | Попытаться добавить контакт с 31 апреля и повторить с 29 февраля 2027 года. В обоих случаях появляется ошибка у поля и контакт не создаётся. |
| Границы периода и порядок | В произвольном порядке добавить контакты с датами вчера, сегодня, завтра, через семь и через восемь дней. На главной видны сегодня, завтра и через семь дней в таком порядке. |
| Несколько контактов с одним днём рождения | Задать двум контактам одну ближайшую дату, одному без года. Оба видны в блоке ровно по одному разу. |
| Переход в новый год | Открыть главную 28 декабря с контактами на 31 декабря и 1 января. Даты идут в этом порядке. |
| Текущий день по Новосибирску | При разнице в календарных днях браузера и Новосибирска открыть главную с контактами на обе даты. Блок показывает контакт на текущую дату Новосибирска, а дата предыдущего дня отсутствует. |
| Високосный год | Открыть главную 27 февраля 2028 года. Тестовый контакт на 29 февраля виден с этой датой. |
| Невисокосный год | Открыть главную 27 февраля 2027 года. Тот же контакт на 29 февраля отсутствует в блоке. |
| Карточка из списка дней рождения | Между «Пора связаться» и поиском найти строку ближайшего дня рождения. Увидеть имя и день с месяцем, перейти по строке и проверить карточку. |
| Пустой период | Оставить контакты без даты и с датой за пределами периода. Под заголовком блока виден текст «В ближайшие дни нет дней рождения». |
| Поиск и фильтр по группе | На главной набрать другое имя и выбрать группу без именинника. Общий список фильтруется, порядок и состав блока сохраняются. |
| Дни рождения другого пользователя | Добавить по контакту с ближайшей датой в двух тестовых аккаунтах. Открыть главную в каждом и увидеть только свой контакт. |
| Появление и исчезновение после изменения | Создать контакт с ближайшей датой, перенести её за период, вернуть и очистить. После каждого сохранения открыть главную и сравнить состав блока. |
| Удаление контакта с ближайшим днём рождения | Удалить специально созданный тестовый контакт через карточку. Проверить отсутствие в блоке и общем списке. |
| Сохранение других данных контакта | Изменить дату рождения у контакта с заметкой и расписанием. Сверить заметку, частоту и следующий срок. |
